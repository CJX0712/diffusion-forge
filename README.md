# Diffusion Forge · 扩散模型实验室

单文件、零依赖、离线可跑的 DDPM 扩散模型实验室。浏览器直接打开 `index.html` 即可。
从零手写全部组件：闭式前向加噪、后验公式、MLP 噪声预测网络、Adam、DDPM/DDIM 采样，约 300 行纯 JS。

## 它做什么

- **前向扩散**：`x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε`（线性 β 调度，T=50）
- **训练**：网络输入 `[x_t, t 的正弦特征]`，目标是预测加入的噪声 ε（标准 DDPM 目标），Adam 优化
- **采样**：DDPM（全链随机）与 DDIM（η=0 时确定性），500–1500 点
- **三种数据集**：四簇高斯 / 瑞士卷 / 双月牙，散点可视化 + 前向加噪演示 + loss / 调度曲线

## 可验证不变量（`_smoke.js`，Node 无头全绿）

1. **前向闭式解 vs 逐步迭代**：同一过程两条独立算法路径，6000 样本矩匹配（3σ 内）
2. **后验代数恒等式**：把 `x_t = √ᾱ_t·x₀` 代入 `q(x_{t-1}|x_t,x_0)` 均值公式，所有 t 精确还原 `√ᾱ_{t-1}·x₀`（< 1e-12）
3. **梯度检验**：MLP 反传解析梯度 vs 中心差分，相对误差 < 1e-5
4. **训练确定性**：同种子两次训练，参数 bit 级相等
5. **生成质量**：DDPM/DDIM 采样 800 点全部覆盖 4 个高斯簇（每簇占比 12–45%），样本散布 ≈ 数据散布
6. **DDIM 确定性**：η=0 同种子 bit 级相同；η=1 恢复随机
7. 边界：T=1 调度、batch=1 训练、小模型采样、矩有限性

## 运行测试

```bash
node _smoke.js    # 引擎不变量
node _probe.js    # 矩对比 + ASCII 密度图（生成 _probe.txt）
node _uicheck.js  # DOM stub 下点遍全部 UI 控件
```

## 原理一图流

```
x₀ --(加噪 β₁…β_T)--> x_T ~ N(0,I)
      训练：网络 ε_θ(x_t, t) ≈ ε
采样：x_T → ε̂ → 逐步去噪（后验均值 + 方差）→ x₀
DDIM：把随机方差换成 η 参数，η=0 时整条链变成确定性 ODE 轨迹
```
